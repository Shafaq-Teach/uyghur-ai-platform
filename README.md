# 2 تىللىق سۈنئىي ئىدراك سۇپىسى (Uyghur AI Platform)

ئۇيغۇرچە ۋە ئىنگىلىزچە 2 تىلدا تولۇق ئىشلەيدىغان، **OpenRouter** ۋە **Google Gemini** سۈنئىي ئىدراك مودېللىرى بىلەن تەمىنلەنگەن بىر پۈتۈن زامانىۋى سۇپا.

---

## 🌟 ئاساسلىق ئىقتىدارلار ۋە مودېللار

1. **پاراڭ بوت (Chatbot) — `/chat`**
   - كۆپ قېتىملىق چوڭقۇر پاراڭ، پىروگرامما، ئەدەبىيات ۋە ئومۇمىي بىلىملەر.
   - رول تاللاش: يازغۇچى، پىروگراممېر، مۇئەللىم، سودا مەسلىھەتچىسى.
   - مودېللار: `google/gemini-2.5-flash`, `google/gemini-2.5-pro`, `deepseek/deepseek-r1`, `anthropic/claude-3.5-sonnet`, `openai/gpt-4o`.

2. **تېكىست تەرجىمە (Translation) — `/translate`**
   - 4 تىل ئارىسىدا تەرجىمە: ئۇيغۇرچە (ئەرەب يېزىقى) ↔ ئىنگىلىزچە ↔ تۈركچە ↔ ئەرەبچە.
   - 7 خىل كەسپىي تەرجىمە ئۇسلۇبى: ئادەتتىكى، رەسمىي، بەدىئىي/ئەدەبىي، ئىلمىي، سودا، ساددا، ئاغزاكى سۆھبەت.
   - RTL/LTR ئاپتوماتىك تەڭشىلىش، تىل ئالماشتۇرۇش (⇄)، ئاۋازلىق ئوقۇش (TTS).

3. **رەسىم ھاسىل قىلىش (Image Generation Studio) — `/image`**
   - ئۇيغۇرچە ۋە ئىنگىلىزچە prompt نى ئاپتوماتىك بېيىتىش.
   - 7 خىل كۆرۈنۈش نىسبىتى: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.
   - سەنئەت ئۇسلۇبلىرى: Realistic, Cinematic, 3D Render, Anime, Watercolor, Cyberpunk, Minimalist.
   - مودېللار: `black-forest-labs/flux-1-schnell`, `flux-1-dev`, `stabilityai/stable-diffusion-3.5-large`, `recraft-ai/recraft-20b`, `imagen-3.0-generate-002`.

4. **ئۇيغۇرچە ئاۋازلىق ئوقۇش (TTS) — `/tts`**
   - تېكىستنى تەبىئىي ئۇيغۇرچە ئاۋازغا ئايلاندۇرۇش.
   - ئاۋاز پېرسوناژلىرى: گۈلنار، يۇنۇس، رەيھان، ئەكبەر.
   - سۈرئەت (0.5x–2.0x) ۋە ئاۋاز ئېگىزلىكى تەڭشىكى، دولقۇنسىمان visualizer، `.wav` چۈشۈرۈش.

5. **مەھسۇلات رەسىمىدىن ئىلان ۋىدېيوسى (Ad Video) — `/ad-video`**
   - **ئالاھىدىلىكى:** 8K كىنو دەرىجىلىك ستۇدىيە سۈپىتى، تاۋار ماكرو كۆرۈنۈشى.
   - مەھسۇلات رەسىمىنى يۈكلەش، 3 كادىرلىق ماكرو كىنو سېنارىيەسى ۋە تەييار ۋىدېيو ھاسىل قىلىش.

6. **ئەسەرلەر تارىخى — `/history`**
   - بارلىق رەسىم، پاراڭ، تەرجىمە ۋە ۋىدېيولارنى كۆرۈش، چۈشۈرۈش ۋە باشقۇرۇش.

7. **سۇپا تەڭشەكلىرى — `/settings`**
   - OpenRouter API ئاچقۇچى ۋە Google Gemini API ئاچقۇچىنى كىرگۈزۈش.
   - ھەربىر بۆلەككە خالىغان OpenRouter ياكى Gemini مودېلىنى ئايرىم بېكىتىش ياكى ئىختىيارىي مودېل كودى كىرگۈزۈش.

---

## 🚀 قوزغىتىش ۋە زىيارەت قىلىش

سېستىما مۇۋەپپەقىيەتلىك پۈتتى ۋە ھازىر تۆۋەندىكى ئادرېستا قوزغىلىپ ئىشلەۋاتىدۇ:
- **توركۆرگۈدە ئېچىش ئادرېسى:** [http://localhost:3000](http://localhost:3000)

قايتا قوزغىتىش كېرەك بولسا:
```bash
npm run start
# ياكى يېڭىلاپ تۇرۇپ ئىشلىتىش ئۈچۈن:
npm run dev
```
